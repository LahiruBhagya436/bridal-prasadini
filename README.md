# Bridal Prasadini — Luxury Bridal Salon Website

A production, marketing website for **Bridal Prasadini Mallawarachchi — Salons & Academy**, a luxury bridal makeup and beauty academy. Built to convert visitors into booked clients, with an elegant, animated, fully responsive design.

🔗 **Live:** _(add your Vercel URL here after deploy)_

## Features
- Elegant, animation-rich UI (hero, services, gallery, testimonials, contact)
- Booking form with validation
- Masonry gallery with lightbox and category filters
- Fully responsive, accessible, and SEO-friendly
- Fast: image optimization and package-import optimization

## Tech stack
- **Next.js 14** (App Router) · **React** · **TypeScript**
- **Tailwind CSS**
- **Framer Motion**, **GSAP**, **Lenis** (smooth scroll & animations)
- **React Hook Form** + **Zod** (forms & validation)
- **Radix UI** primitives · **lucide-react** icons
- Deployed on **Vercel**

## Getting started
```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
npm start        # run production build
```
